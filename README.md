🏨 Smart Hotel Reservation System

A modern and intelligent hotel room reservation web application that allows users to book rooms efficiently with a visually interactive dashboard and smart allocation logic.
This system is designed to provide a smooth and user-friendly booking experience while optimizing room allocation and minimizing travel time between rooms.

🚀 Features

🔐 User Login & Signup authentication

🏨 Smart room booking system (auto best room selection)

🎨 Professional and responsive UI

📊 Real-time room visualization (floor-wise)

🟢 Available / 🔴 Occupied / 🟢 Booked room highlighting

🎲 Random occupancy generator for testing

♻ Reset booking functionality

📜 Booking history tracking

⚡ Fast backend using Node.js & Express

🌐 REST API based architecture

🧠 Smart Logic Used

The system intelligently books nearest available rooms on the same floor whenever possible to reduce travel time for guests. If rooms are not available on one floor, it allocates rooms across floors with minimum distance.
